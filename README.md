# Au Au Passeios RJ

Landing page estática de divulgação dos passeios para cães em Copacabana e bairros próximos da Zona Sul do Rio de Janeiro.

## Publicação

O site é estático e pode ser publicado pelo GitHub Pages a partir da branch `main`, pasta `/`.

Arquivos principais: `index.html`, `styles.css`, `main.js` e `assets/`.
